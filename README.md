# 다시, 캠페인 — 3-2 캠페인 기획 실습 웹앱 (롯데 LIFT)

게임으로 몸풀기 → 개념 학습 → 케이스 C 자료실 → 활동시트 ①~⑪ 작성 → 발표·상호평가를 한 앱에서 진행하는 수업용 웹앱입니다.
외부 패키지 없이 Node.js(18 이상) 기본 기능만 씁니다. 기존 「달콤상점 마케팅 게임」과 같은 방식으로 배포합니다.

## 수업 운영 순서
| 순서 | 탭 | 내용 |
|---|---|---|
| 1 | 게임 | 용어 빙고(강사가 설명 카드 공개) · 글자 조합 A(용어) · 글자 조합 B(슬로건 → 시트 ③으로 보내기) · 사실일까 판단일까 |
| 2 | 개념 학습 | 시트 11장의 목적·공식·흔한 실수 + 확인 퀴즈 |
| 3 | 케이스 C | 부산본점 · 50~64세 여성 사례의 사실 카드 12장 (강사 풀이는 공개 스위치로) |
| 4 | 캠페인 실습 | 활동시트 ①~⑪ · 자동 계산(채널·예산 합계, 금액, 1인당 획득 비용, 손익분기) · 자동 점검 · 힌트 3단계 · 케이스 C 자료 가져오기 · ⑩ 자동 채움과 1페이지 포스터 · 인쇄/PDF |
| 5 | 발표·평가 | 8분+4분 타이머 · 다른 조 4항목 × 25점 평가 |

- **강사 화면**: 주소 끝에 `#teacher`를 붙여 엽니다 (예: `https://내주소/#teacher`). 교육생에게는 이 주소를 알려 주지 마십시오.
  - 진행 순서 / 빙고 설명 카드 넘기기 / 조별 진행률과 시트 읽기·두 조 비교 / 시트별 동래점 모범답안 + 케이스 C 풀이 + 공개 스위치 / 점수판(게임 점수 자동 합산 + 조정) / 평가 결과 공개 / JSON·CSV 내보내기 / 수업 데이터 초기화
- 로그인은 없습니다. 주소를 아는 사람은 누구나 열 수 있으니 수업 중에만 공유하십시오.

## Railway 배포
1. 이 저장소를 Railway에서 New Project → Deploy from GitHub repo로 연결합니다.
2. 서비스 → Settings → Networking → Generate Domain
3. Variables에 `DATA_DIR = /data` 추가, Settings → Volumes → Add Volume, Mount path `/data`
   (볼륨이 없으면 재배포할 때 조별 기록이 지워집니다)

## 로컬 실행 · 점검
```
node server.js      # http://localhost:3000
npm test            # 서버 API 점검
```

## 내용 바꾸기
수업 콘텐츠(시트 양식, 모범답안, 케이스 C 카드, 게임 문제)는 모두 `public/data.js`에 있습니다. 다른 반·다른 케이스로 바꿀 때는 이 파일만 고치면 됩니다.
원자료 전문은 `docs/source/`, 분석과 제작 기준은 `docs/campaign-webapp-prompt.md`에 있습니다.
