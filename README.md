# 캠페인 기획 연습장 — 3-2 캠페인 기획 실습 (롯데 LIFT 부산3반)

「3-2 캠페인 기획 실습 · 장별 강의 가이드」(PPT 56장 원고)를 그대로 옮긴 수업·복습용 웹앱입니다.
외부 패키지 없이 Node.js(18 이상) 기본 기능만 씁니다. 실습 케이스 수치는 PPT에 표기된 교육용 가상 데이터입니다.

## 탭 구성 (가이드 6부 웹앱 구성안 기준)
| 탭 | 내용 |
|---|---|
| 홈 | 강의를 여는 세 가지 질문 · 오늘의 흐름(5단계·실습 12개) · 진도(본 장 /56, 아는 용어 %, 게임 /9, 조 활동지 %) · 이어서 보기 · 조/팀명/**우리가 고른 지점** |
| 장별 대본 | 1~56장: 핵심 한 줄 → 선생님이 알아 둘 것 → 대본 → 진행 순서·돌면서 볼 것 → 넘어가는 한마디. '다 봤어요', 대본 가리기(연습), **크게 보기(강의 모드)**, ←→ 키, 장마다 용어 칩 |
| 용어사전 | 148개 · 14분류 · 검색 · 카드로 외우기 · '알아요' 체크 · 나오는 장 바로가기 |
| 게임 | 가이드 게임 6종(캠페인/프로모션 · 사례-유형 메모리 · 신호→트렌드 · KPI 퍼널 · 인사이트 판정관 · 도달·획득비용 계산기) + 실시간 용어 빙고 + 글자 조합(용어 · 슬로건 → 활동지 ④로 보내기) |
| 실습 가이드 | 실습 ①~⑫ 시간 · 진행 순서 · 돌면서 볼 것 · 활동지/대본/예시 장 바로가기 |
| 캠페인 활동지 | 워크시트 ①~⑫ 조별 공동 작성 · 자동 계산(도달, 예산 금액, 1인당 획득 비용 vs 지난번, ⑥↔⑨ 비중 일치) · 자동 점검 · 힌트 3단계 · 케이스 자료 가져오기 · **우리 지점 자료 찾기**(보도자료·인스타·데이터랩·공공데이터 검색 바로가기) · MOOD SHIFT 예시와 비교 · ⑪ 자동 채움 + 1페이지 포스터 · 인쇄/PDF |
| 프로모션 vs 캠페인 | 2장 비교표 · 우산 구조 · 3-1 케이스 C와의 차이 |
| 발표·평가 | 8분(2분 × 4) + 질의 4분 타이머 · 4항목 × 25점 상호 평가 |
| 강사 (`주소/#teacher`) | 학생 화면을 N장으로 맞추기 · **공용 실습 타이머**(모든 학생 화면에 표시) · 빙고 진행 · 조별 진행률/시트 읽기/예시와 비교 · 예시 답안 잠금(수업 모드)·해제(자습 모드) · 점수판 · 평가 결과 공개 · CSV/JSON 내보내기 · 초기화 |

- 개인 진도(본 장·아는 용어·게임 최고점)는 각자의 브라우저에, 조 활동지·게임 점수·평가는 서버에 저장됩니다.
- 로그인은 없습니다. 주소를 아는 사람은 누구나 열 수 있으니 수업 중에만 공유하고, `#teacher` 주소는 교육생에게 알려 주지 마십시오.

## Railway 배포
1. 이 저장소를 Railway에서 New Project → Deploy from GitHub repo로 연결합니다.
2. 서비스 → Settings → Networking → Generate Domain
3. Variables에 `DATA_DIR = /data` 추가, Settings → Volumes → Add Volume, Mount path `/data`
   (볼륨이 없으면 재배포할 때 조별 기록이 지워집니다)

## 로컬 실행 · 점검
```
node server.js      # http://localhost:3000   (강사: http://localhost:3000/#teacher)
npm test            # 서버 API 점검
```
